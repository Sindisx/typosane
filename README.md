# TypoSane

> Рабочее международное название. Текущее техническое имя проекта — Словолад.
> Продукт находится в закрытой alpha-разработке; публичной загрузки пока нет.

**Автокоррекция там, где macOS обычно не помогает.**

TypoSane — локальный системный слой коррекции ввода. Он исправляет слова прямо
во время набора в совместимых мессенджерах, браузерах, рабочих приложениях и
игровых чатах — без отдельного редактора и отправки переписки в облако.

> Пишите как чувствуете. Отправляйте как задумали.

## Что в нём особенного

- один предсказуемый автокорректор для совместимых системных полей;
- полностью локальная и офлайн-обработка текста;
- исправление тяжёлых опечаток, повторов, перестановок и неверной раскладки;
- словарные кандидаты плюс контекст — без генерации произвольных фраз;
- автоматическая замена только при достаточной уверенности;
- нативная панель вариантов для неоднозначных случаев;
- безопасная отмена свежего исправления;
- персональные замены, имена, сленг и список исключений;
- профили от экономного до максимального локального анализа;
- системный Secure Input и корректно помеченные защищённые поля пропускаются;
- токены с цифрами и короткие слова пропускаются, а распознаваемые терминалы и
  редакторы кода исключаются по умолчанию;
- нет истории клавиш, облачного журнала и доступа к буферу обмена.

Первая русскоязычная alpha разрабатывается для macOS 14+ и проверяется на Apple
Silicon; universal `arm64 + x86_64` release пока не готов. Windows, Linux и
другие языки входят в долгосрочное направление, но пока не заявлены как
поддерживаемые.

## Честная совместимость

macOS не даёт универсального публичного API для каждого поля. Приложение
рассчитано на стандартные AX-editable поля и часть web/Electron-интерфейсов.
Canvas-редакторы, remote desktop, защищённый ввод и некоторые игровые поля
могут не принять замену. Мы будем публиковать проверенную таблицу
совместимости, а не обещание «работает абсолютно везде».

## Приватность

Обработка выполняется на устройстве. Во время набора в оперативной памяти
находятся ограниченный token и контекст, ожидающие варианты и данные последнего
исправления; постоянная история переписки не создаётся. Подробнее:
[PRIVACY.md](PRIVACY.md).

## Безопасность
