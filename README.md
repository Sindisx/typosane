# TypoSane

> TypoSane пока рабочее международное имя. Внутри приложение всё ещё
> называется Словолад.

## Автокоррекция там, куда macOS обычно не добирается

Если совсем коротко, это Т9 для компьютера.

Пишешь бывшей в три ночи, ругаешься в игровом чате или на ходу отвечаешь в
мессенджере. Пальцы уже едут, а перечитывать каждую строчку поздно. Словолад
ловит опечатки прямо в поле ввода. Ничего не надо таскать в отдельный редактор,
и сам текст не улетает в облако.

Он не сочиняет сообщения за тебя. Он просто помогает отправить именно ту хуйню,
которую ты хотел написать, а не то, что получилось между третьим бокалом и
Enter.

## Уже можно скачать

[TypoSane / Slovolad v0.1.0-alpha.1](https://github.com/Sindisx/typosane/releases/tag/v0.1.0-alpha.1):
готовый `Slovolad.app` без исходников самого приложения и закрытого ядра.
Нужны macOS 14 или новее и Mac на Apple Silicon (`arm64`).

Сейчас это ранняя словарная сборка. Локальный словарь и системная коррекция
работают, а обе RuBERT/Core ML модели из неё убраны. Сначала нормально закроем
вопрос с лицензиями и атрибуцией, затем планируем вернуть контекстное
ML-ранжирование. В интерфейсе пока ещё может встретиться название этих моделей,
но внутри архива их нет.

Сборка подписана ad-hoc и пока не нотарифицирована Apple. macOS может
заблокировать первый запуск. Инструкция и SHA-256 лежат на странице релиза.
Для работы поверх других приложений macOS попросит разрешения Accessibility и
Input Monitoring.

## Что уже умеет

- ловит повторы букв, перестановки, неверную раскладку и часть тяжёлых
  опечаток;
- уверенные исправления применяет сам, неоднозначные может показать как
  варианты, а сомнительные оставляет как есть;
- даёт быстро отменить последнее исправление;
- учитывает пользовательские замены, имена, сленг и слова, которые трогать
  нельзя;
- работает локально, без сетевого API, истории сообщений и чтения буфера
  обмена;
- пропускает Secure Input и поля, которые приложение честно пометило как
  защищённые;
- по умолчанию не лезет в распознанные терминалы и редакторы кода.

## Где может не сработать

У macOS нет одного нормального API для любого поля ввода. Словолад рассчитан на
обычные AX-editable поля и часть web/Electron-интерфейсов. Canvas-редакторы,
remote desktop, защищённый ввод и некоторые игровые чаты могут не принять
замену.

Обещать "работает вообще везде" было бы враньём. Будем проверять приложения по
одному и собирать нормальную таблицу совместимости.

Пока доступна только русскоязычная версия для Apple Silicon. Universal
`arm64 + x86_64`, Windows, Linux и другие языки ещё впереди.

## Что происходит с текстом

Он остаётся на Mac. Во время набора в памяти лежат текущий токен, небольшой
контекст, варианты, данные активного поля и последнего исправления. Настройки,
пользовательские замены и исключения сохраняются локально. Постоянную историю
переписки Словолад не ведёт.

Подробности без рекламной шелухи лежат в [PRIVACY.md](PRIVACY.md).
